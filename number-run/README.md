# 숫자 달리기 (테스트 버전)

만 4세 아이용 덧셈·뺄셈 러너 게임. HTML 파일 하나(`index.html`)와 숫자 스킨 이미지(`skins/`)로 되어 있습니다.

## 실행
- 폰에서: 이 폴더를 웹에 올리면 바로 됩니다(GitHub Pages 등). `index.html`과 `skins/` 폴더가 같은 위치에 있어야 합니다.
- PC에서: 이 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속. 키보드 ←/→ 로도 움직일 수 있습니다.

## 규칙
- 1에서 시작해서 앞으로 달립니다. 화면을 누른 채 좌우로 움직여요.
- 초록 배지(+) 숫자 친구와 만나면 더하기, 빨간 배지(−) 숫자와 장애물은 빼기.
- 만날 때마다 멈춰서 `1 + 7` → `= 8` 장면을 보여주고 소리로 읽어준 뒤, 8이 되어 다시 달립니다.
- 0이 되면 게임 아웃, 도착선까지 가면 클리어(최종 숫자로 별 1~3개).
- 한 판은 약 40~46초.

## 난이도 조절
`index.html` 위쪽 `설정` 부분에서 바꿉니다.
- `STAGES`: 스테이지별 줄 개수(`rows`), 최대 숫자(`max`), 더하기/빼기/장애물 숫자 범위, 0이 되는 함정 허용(`trap`), 줄 종류 비율(`mix`)
- `SPEED`, `SPACING`: 달리기 속도와 숫자가 나오는 간격 (한 판 길이)
- `EVENT_T`: 덧셈·뺄셈 장면 길이
- `UNLOCK_ALL`: 테스트용으로 모든 스테이지를 열어 둠 (`false`면 앞 스테이지를 깨야 열림)

## 50 넘는 숫자
스킨이 있는 숫자는 1~50, 54, 55, 56, 60, 63, 64, 70, 72, 80, 81, 90, 100 입니다.
더하기·빼기·장애물 숫자는 나타나는 순간의 현재 숫자를 보고 정해서, 결과가 항상 스킨이 있는 숫자(또는 0)가 되도록 만듭니다.

## 스킨 이미지
`skins/N.png`는 올려주신 JPG에서 흰 배경을 지우고 크기를 줄인 것입니다. 새 이미지로 바꿀 때는 같은 이름의 투명 배경 PNG로 넣으면 됩니다.
