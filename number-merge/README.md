# 숫자 합체 (넘버블럭스 덧셈·마이너스 게임)

숫자 블록을 손가락으로 끌어서 다른 블록 위에 놓으면 합체합니다.
어두운 **마이너스 블록**(빨간 `−3` 표시)을 붙이면 그만큼 작아집니다.

## 실행
- **폰에서 (가장 쉬움):** `숫자합체.html` 파일 하나만 폰에 받아서 크롬 등 브라우저로 열면 됩니다. 그림·목소리·글꼴이 모두 들어 있어 인터넷이 없어도 됩니다.
  다시 만드는 법: `python3 build_offline.py Jua-Regular.ttf` (index.html을 고친 뒤 다시 실행)
- 웹에 올려서: 이 폴더를 그대로 올리면 됩니다(GitHub Pages 등). `index.html`, `skins/`, `voice/`가 같은 위치에 있어야 합니다.
- PC에서: 이 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.

## 놀이 방법
- **스테이지 1~5 (더하기):** 위에 나온 숫자를 블록 합체로 만들어요. 1~5 → 1~50까지 점점 커집니다.
- **스테이지 6~10 (마이너스):** 마이너스 블록이 섞여 나옵니다. `7` + `−2` → `5`.
  8단계부터는 만들 숫자가 마이너스일 때도 있어요(`−4` 만들기).
- 한 스테이지는 5문제. 도움 없이 가장 적게 합체해서 맞히면 "한 번에 척척"이고, 그 수로 별 1~3개.
- 플러스와 마이너스 블록이 같은 크기면 `0`이 되어 펑! 사라집니다.
- 50보다 커지거나 −50보다 작아지는 합체는 튕겨 나옵니다(그림이 1~50까지라서).
- **도와줘:** 합체하면 좋은 두 블록이 반짝입니다. **처음부터:** 문제를 처음 상태로 되돌립니다.
  더 이상 만들 수 없게 되면 "처음부터" 버튼이 알려줍니다.
- 블록을 톡 누르면 숫자를 읽어줍니다.
- **자유 놀이:** 아래 상자에서 1~10 블록(더하기/마이너스)을 끌어 와서 마음대로 합체해요. 블록을 상자로 다시 끌어 오면 없어집니다.

## 조절
`index.html` 위쪽 `설정` 부분에서 바꿉니다.
- `STAGES`: 스테이지별 최대 숫자(`max`), 정답 블록 수(`parts`), 정답이 아닌 블록 수(`extra`), 마이너스 블록(`minus`), 만들 숫자가 마이너스일 확률(`negGoal`)
- `PUZZLES`: 스테이지당 문제 수, `UNLOCK_ALL`: `false`면 앞 스테이지를 깨야 다음이 열림
- `TRAY_NUMS`, `FREE_MAX_BLOCKS`: 자유 놀이 상자 숫자 범위, 화면에 둘 수 있는 블록 수

## 그림·목소리
- `skins/1.png ~ 50.png`: 숫자 달리기(`number-run/skins/`)의 그림을 그대로 가져왔습니다.
  마이너스 블록은 같은 그림을 어둡게 하고 보라색 빛을 둘러서 보여줍니다(따로 그림 파일 없음).
- `voice/*.mp3`: 숫자 달리기와 같은 목소리(Supertonic, 오픈소스 TTS)입니다. `p{n}` "일 더하기", `m{n}` "일 빼기", `b{n}` "칠은", `r{n}` "바로 팔!"
- 미리 만든 목소리에는 "마이너스"가 없어서, 결과가 마이너스이거나 마이너스 숫자끼리 합칠 때와 "○을 만들어 볼까요?", 블록 숫자 읽기는 휴대폰 기본 목소리로 읽습니다.
