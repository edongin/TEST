# 넘버블럭스 스케이트 14

휴대폰 브라우저에서 바로 하는 스케이트보드 달리기 게임입니다. `index.html` 한 파일만 있으면 됩니다 (이미지 포함, 인터넷 필요 없음 · 글꼴만 온라인에서 불러옴).

- 스테이지 100개 (1–5 연습, 6–33 놀이터, 34–66 공원, 67–100 도심)
- 조작: ◀ ▶ 레인 이동, ▲ 점프, ▼ 숙이기 (버튼 또는 화면 쓸기)
- 점프대: 날아오르면 나오는 동그라미를 타이밍 맞춰 누르기 → 퍼펙트/그레이트/노멀/배드
- 레인(그라인드): 화살표 줄로 가면 올라타고, 연타
- 갈림길: 14가 7 + 7로 나뉘어 각자 점프, 끝나면 다시 합체
- 코인으로 상점에서 스티커 / 14 색깔 / 보드 구입. 깬 스테이지는 다시 해서 코인 모으기 가능
- 설정에서 난이도(쉬움/보통/어려움) 변경. 진행 상황은 그 브라우저에 저장됩니다

## 수정 방법
`src/game.html`을 고친 뒤 `python3 src/build.py`를 실행하면 캐릭터 이미지(`src/images.json`)를 넣어 `index.html`을 만듭니다.
