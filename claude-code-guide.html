Claude로 할 수 있는 일

사람들이 Claude에게 가장 많이 맡기는 일 10가지입니다. 궁금한 카드를 누르면 그 안에서 할 수 있는 일과 바로 따라 써볼 수 있는 요청 문장이 나옵니다.

해본 것 표시는 이미 직접 써본 분야예요. 여기서부터 넓혀가면 쉽습니다.

어떻게 부탁하면 잘 해줄까

상황을 먼저 말하기“보고서 써줘”보다 “팀장님께 올릴 주간 보고서, A4 한 장, 표 포함”처럼 누가 보고 어떤 모양인지 알려주세요.
자료는 그대로 붙이기문서, 사진, 엑셀, PDF를 올리거나 붙여넣으면 그걸 바탕으로 작업합니다.
한 번에 끝내려 하지 않기첫 결과를 보고 “더 짧게”, “표로 바꿔줘”처럼 이어서 고쳐달라고 하면 됩니다.
마음에 든 방식은 저장자주 쓰는 서식이나 말투는 “앞으로 이 형식으로 해줘”라고 정해두거나 프로젝트에 넣어두세요.

어디서 쓰나요

Claude 채팅 (claude.ai, 앱)대부분의 일은 여기서 충분합니다. 글쓰기, 검토, 요약, 조사, 질문, 간단한 게임이나 페이지 만들기까지 됩니다.
Claude Code내 컴퓨터의 폴더나 파일을 직접 열어서 여러 개를 한꺼번에 고치거나, 프로그램을 만들고 실행까지 해야 할 때 씁니다. 처음에는 채팅부터 익숙해진 뒤 넘어가도 늦지 않습니다.
