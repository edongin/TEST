    CLAUDE CODE · 실무 활용 가이드

    Claude Code 활용 설명서

    Claude Code는 터미널, IDE, 데스크톱 앱, 웹에서 코드베이스를 직접 읽고 수정하고 명령을 실행하는 Anthropic의 코딩 에이전트입니다. 이 문서는 공식 설명서 내용을 사람들이 실제로 자주 맡기는 작업 10가지로 묶어 다시 정리했습니다.

    A. 공식 설명서가 있습니다

    Anthropic이 공식 설명서를 제공합니다. 한국어 페이지도 있으며, 이 가이드의 각 분류 끝에 관련 공식 페이지를 연결해 두었습니다.

    Claude Code 개요 (한국어)code.claude.com/docs/ko/overview 빠른 시작설치부터 첫 작업까지 일반적인 워크플로공식 작업 예시 모음 Overview (영어 원문)가장 먼저 갱신되는 원문 Claude Code Best PracticesAnthropic 엔지니어링 블로그 설정 (settings.json)권한, 환경변수, 모델

    B. 작업 분류 기준

    작업을 셀 때 “얼마나 오래 했는가”가 아니라 “한 계정이 한 번 맡긴 반복 단위의 작업”을 1건으로 셉니다. 예를 들어 3시간 동안 버그 1개를 붙잡고 있었다면 1건, 30분 동안 커밋 메시지를 5번 만들었다면 5건입니다.

    1건의 시작사용자가 하나의 목표를 맡김 (예: “로그인 오류 고쳐줘”)
    1건의 끝결과물이 나와 사용자가 수락·커밋하거나 다음 목표로 넘어감
    세지 않는 것같은 목표 안에서 오가는 추가 질문, 수정 요청, 재시도
    [목표 맡김] → 탐색 → 계획 → 실행(수정·명령) → 검증(테스트·확인) → [수락/커밋] = 1건 ↑______________________ 같은 목표의 재요청은 같은 건으로 묶음 ____________________|

    아래 순위는 Anthropic이 공개한 사용 경향(소프트웨어 개발 작업이 가장 큰 비중이며, 그중 기능 구현과 디버깅이 가장 많다는 보고)과 공식 워크플로 문서를 바탕으로 이 기준에 맞춰 정리한 추정 순서입니다. 정확한 통계 수치가 아니므로 팀 내부에서 실제 사용 기록을 이 기준으로 세어 보정하는 것을 권합니다.

    D. 모든 작업에 공통으로 쓰는 기본기

    설치와 실행

    curl -fsSL https://claude.ai/install.sh | bash   # 기본 설치 (macOS·Linux·WSL)
npm install -g @anthropic-ai/claude-code        # npm으로 설치
cd 내-프로젝트 && claude                           # 프로젝트 폴더에서 실행
claude -p "이 저장소 구조를 요약해줘"                # 대화창 없이 한 번만 실행

    자주 쓰는 명령

    명령 / 키하는 일
    /init프로젝트를 분석해 CLAUDE.md(프로젝트 설명서) 초안을 만듭니다.
    /clear대화 기록을 비웁니다. 작업 1건이 끝나면 비우고 다음 건을 시작하는 습관이 좋습니다.
    /compact긴 대화를 요약해 맥락 공간을 확보합니다.
    /model사용할 모델을 바꿉니다.
    /permissions허용할 명령과 도구를 관리합니다.
    /mcp연결된 외부 도구(MCP 서버)를 확인합니다.
    Shift+Tab권한 모드를 바꿉니다. 계획 모드(Plan mode)에서는 수정 없이 계획만 세웁니다.
    Esc / Esc 두 번진행 중인 작업을 멈춥니다 / 이전 메시지로 되돌아갑니다.
    @파일경로특정 파일을 대화에 바로 포함합니다.
    # 로 시작입력한 내용을 메모리(CLAUDE.md)에 저장합니다.

    확장 기능 요약

    CLAUDE.md빌드 명령, 코드 규칙, 주의사항을 적어 두면 매 세션 자동으로 읽습니다. 공식 문서
    슬래시 명령 · 스킬자주 쓰는 지시문을 .claude/commands/나 스킬로 저장해 재사용합니다. 공식 문서
    서브에이전트탐색·리뷰처럼 따로 떼어 맡길 일을 별도 에이전트로 돌립니다. 공식 문서
    훅(Hooks)“파일 수정 후 항상 포매터 실행”처럼 자동 규칙을 겁니다. 공식 문서
    MCPGitHub, Slack, DB, 브라우저 같은 외부 도구를 연결합니다. 공식 문서
    GitHub Actions이슈·PR에서 @claude를 불러 자동으로 작업시킵니다. 공식 문서

    E. 잘 쓰는 습관

    1건 = 1세션작업 하나가 끝나면 /clear. 이전 작업의 맥락이 다음 작업을 흐리지 않습니다.
    탐색 → 계획 → 실행큰 작업은 먼저 “코드만 읽고 계획을 세워줘”라고 맡긴 뒤 계획을 확인하고 실행시킵니다.
    검증 수단을 함께 주기테스트 명령, 기대 결과, 스크린샷처럼 Claude가 스스로 확인할 방법을 알려주면 결과가 좋아집니다.
    구체적으로 지시“고쳐줘”보다 “src/auth.ts의 토큰 만료 처리에서 401이 무한 반복되는 문제를 고쳐줘”가 낫습니다.
    반복되면 저장같은 지시를 세 번 이상 했다면 CLAUDE.md나 슬래시 명령으로 만듭니다.
    권한은 점진적으로처음엔 승인하며 쓰고, 안전한 명령만 /permissions에 추가해 확인 요청을 줄입니다.
    공식 설명서 기준으로 정리했으며 기능은 자주 바뀝니다. 최신 내용은 code.claude.com/docs에서 확인하세요.
